# Linux

Раздел по администрированию Linux: полезные команды, типовые задачи, диагностика.

## Файлы и каталоги

| Команда | Описание |
|---|---|
| `ls -lah` | Список файлов с правами и размерами |
| `find /etc -name '*.conf'` | Поиск файлов по имени |
| `grep -rn 'text' /path` | Поиск текста в файлах рекурсивно |
| `du -sh /var/*` | Размер каталогов |
| `df -h` | Свободное место на дисках |

## Процессы и сервисы

```
ps auxf                        # Дерево процессов
top / htop                     # Мониторинг в реальном времени
systemctl status nginx         # Статус сервиса
journalctl -u nginx -f         # Логи сервиса (tail -f)
kill -9 <PID>                  # Принудительно завершить процесс
```

## Сеть

```
ip a                           # Интерфейсы и адреса
ip r                           # Таблица маршрутизации
ss -tulpn                      # Открытые порты
ping -c 4 8.8.8.8              # Проверка доступности
ip neigh                       # Таблица ARP (соседи)
```

## Диски

```
lsblk                          # Дерево блочных устройств
mount | column -t              # Смонтированные ФС
smartctl -a /dev/sda           # SMART диска
```

## Полезное

```
history | grep ssh             # История команд
!!                             # Повторить последнюю команду
sudo !!                        # Повторить с sudo
tar czf backup.tar.gz /path    # Создать архив
tar xzf backup.tar.gz          # Распаковать архив
```
